# Be — marketing website kit

Interactive 3-screen marketing site (Home / Story / Join) composed from the Be component library. This is a **proposal**, not a recreation — no existing product was provided. Nav is client-side; the Join form validates and fires a Toast; the hero's "What is Be?" opens a Dialog.

Files: `index.html` (shell: header, footer, screen switching) · `Home.jsx` · `Story.jsx` · `Join.jsx`.
