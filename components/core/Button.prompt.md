Pill action button; honey `primary` is the single loud CTA per view, `secondary` is ink-outlined, `ghost` for quiet actions, `danger` clay, `inverse` for ink bands.

```jsx
<Button onClick={go}>Start being</Button>
<Button variant="secondary" size="lg">Learn more</Button>
<Button variant="ghost" size="sm" icon={<ArrowIcon/>}>Skip</Button>
```

Sizes sm 32 / md 40 / lg 48. Press = scale(.98); hover darkens one step. Sentence case labels, no exclamation points.
