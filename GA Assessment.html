Be — GA Assessment

Full-source audit for general availability: what the system can do today, what this revision fortified, and where it can grow. Version 1.0.0-rc.1 · 1 September 2026

Scope. Every folder in the project: tokens, components, guidelines, both UI kits, the PWA build, sealed files, guides, and research. "GA" is read as general availability — ready for the public, not just a demo. The openclawseed folder from the earlier thread isn't attached here; its consent ethos is already folded into the readme and remains the standard this audit measures against.

1 · Verdict

Ready for GA as a web app and installable PWA, with one release step (HTTPS hosting) and two decisions (license, contact line). The circle (Hive) ships honestly labeled as a sample; a real circle needs the backend described in §5. The brand, tokens, components, research grounding, and accessibility foundations are production-grade now.

2 · Capabilities — what the source can do today

Design system

  • Drop-in tokens via one stylesheet: color, type scale, spacing, radius, shadow, motion, a11y.
  • 14 React components in one precompiled bundle; no build step to consume.
  • Specimen cards for every foundation, brand principle, and research claim.
  • Agent-ready: SKILL.md + readme.md let Claude Code build on-brand.
  • Logo set in three variants plus comb pattern, all vector.
  • Voice rules precise enough to lint copy against (sentence case, no hype, one metaphor).

The app

  • One cited finding per day, rotating evenly through eight; "why we trust it" with caveats.
  • Try / rest / change my mind — keyed to the day, kept on-device.
  • Settle: acknowledge → comprehend → measure → manage, sized to the charge.
  • Learning beside the person: plain counts per finding and charges met; days noted.
  • Take my counts with me — a text file of arithmetic; nothing else exists.
  • Ask Be to forget everything — one plain confirmation, honored instantly.
  • Consent switches all off by default; quiet evenings on by default (an interruption is the thing that needs consent).
  • Circle view that reflects your own sharing switch truthfully.
  • Works with no network, from a double-click or as an installed app on iOS, Android, macOS, Windows.
  • Recovers from a render fault without losing state; tells you when a window can't remember.

3 · Fortifications in this revision

  • Day-keyed answers. Answers were keyed by finding, so after one 8-day cycle every morning already looked answered. Now keyed by date; "change my mind" also retracts that day's count.
  • Even rotation. Finding choice used day-of-month, repeating on the 1st/9th/17th/25th and resetting monthly; now a running day count.
  • Store v2. app-store.js: schema validation, migration from v1 (keeps switches and counts), capped log, safe writes, a visible notice when storage is unavailable, forget and export.
  • Phone fit. Viewport meta was missing — the installed app rendered at desktop width. The frame now fills small screens edge to edge with safe-area padding.
  • Honesty fixes. "Catch up with my circle" previously claimed your circle knew you were well even with sharing off. The circle is now labeled a sample, includes you only when sharing is on, and states exactly what leaves.
  • Learning surfaced. The readme promised a "What Be is learning — beside you" card; the code held the counts but showed nothing. The card now exists, following the four rules.
  • Time to read. Toasts stay 6 seconds and pause while hovered or focused (were 3.2 s).
  • Component a11y. Tabs and Dialog as in §1.
  • PWA. Cache-first with background refresh so updates arrive on the next open; cross-origin requests untouched; only navigations fall back to the shell; manifest id, lang, categories, split icon purposes; privacy.html; color-scheme and no-referrer metas.
  • Wording reconciled. Forgetting is "one plain ask" (a confirmation is the in-the-moment ask the consent principles require; it also prevents accidental loss).

4 · Production potentials

  • Consumer app — the PWA today; native wrappers (Capacitor for stores, Tauri for desktop) reuse the same folder unchanged.
  • Circles for rooms — workplaces, classrooms, clinics' waiting rooms, recovery groups: a shared morning finding and a Settle practice, no scores. Non-medical by design; the Charge protocol is the differentiator.
  • Design system as product — a consent-first, common-congruency UI kit is rare; wellness organizations could license or fork it (decide the license first).
  • Research loop — with a backend, opt-in blended counts (differential-privacy lineage) could tell partner researchers which framings people actually try, feeding the findings editorial cycle.
  • Logia as curriculum — the ledger of fields, definitions, and verified findings is a teaching resource in its own right.

5 · Trajectories

Seed — next 2–4 weeks · GA on the web

  1. Host pwa/ on any static HTTPS host; confirm install on iPhone, Android, Mac, Windows.
  2. Choose a license (see §7) and fill the contact line in pwa/privacy.html.
  3. Invite a first circle by link; collect experience through the guides' feedback loop, not telemetry.
  4. Assistive-technology pass: one screen-reader user, one switch-access user, one low-vision user.

Comb — 1–6 months · a real circle, still consent-first

  1. Backend for circles: device-generated keys, invite codes, no accounts or emails; the server stores only per-day try/rest counts per circle, released only above a minimum circle size.
  2. Morning note as an opt-in Web Push, honoring the quiet-evenings switch; the existing switches become live.
  3. Build step: precompile JSX and use production React (removes in-browser Babel, roughly 2 MB and a second of startup); self-host the fonts (OFL).
  4. Night paper: a dark palette that stays warm; prefers-color-scheme.
  5. Findings editorial: a second reviewer per finding, a re-verification date, and a place to retire a finding when evidence changes.
  6. Localization: the copy is compact and plain — translate the voice rules before the strings.

Hive — 6–18 months · the loop closes

  1. Aggregate, anonymized counts flow back to the research layer; publish what was learned in the same plain voice.
  2. Store distribution via wrappers; privacy labels are simple because the data is.
  3. Circle types for rooms (§4) with facilitator guides derived from the Client Guide.
  4. Settle grows from evidence: e.g. paced-breathing variants, movement prompts, all cited and caveated.

6 · Risks — stated plainly

  • Medical boundary. Be offers research reminders, not advice. Keep the disclaimer in the app and guides; never add symptom tracking or diagnostic language.
  • Evidence drift. The breath finding is early evidence (~100 people) and the hug finding is correlational — both are labeled; keep labels when copy is edited.
  • Storage eviction. Browsers may clear site data for rarely used, uninstalled sites (Safari after 7 days of non-use). Installing the app avoids it; "Take my counts with me" is the safety net.
  • Update lag. Cache-first means a new version appears on the second open after a release. Bump sw.js's cache name on every re-seal.
  • Circle re-identification. Small circles make "1 of 3 resting" identifying. The backend must hold counts below a minimum circle size (suggest 5) and never expose per-person status by default.
  • Larger text. Implemented with CSS zoom; works in current browsers (Firefox 126+). A rem-based scale is the durable path.

7 · Decisions needed from the founder

  • License for the design system and app (e.g. open license vs. proprietary). Nothing ships legally clean without one.
  • Contact line for the privacy page and store listings.
  • Hosting: who runs the static host and, later, the circle service.
  • Re-verification cadence for findings (suggest every 12 months, or when a cited paper is retracted or superseded).
